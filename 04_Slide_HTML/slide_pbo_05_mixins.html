Fondasi Arsitektur

Pewarisan Berganda & Diamond Problem

Diamond Problem

  • Terjadi jika class D mewarisi B dan C yang sama-sama anak A.
  • B dan C menimpa method yang sama.
  • Bahasa C++/Java melarang atau membatasinya.

Solusi Python: MRO

  • Algoritma C3 Superclass Linearization.
  • Urutan penelusuran konsisten tanpa ambiguitas.
  • Dapat diinspeksi lewat Class.__mro__.

Referensi: Python Object-Oriented Programming (4th Edition).

Implementasi Teknis

Mixin Pattern

Karakteristik Mixin

  • Class mandiri berfokus pada satu kapabilitas spesifik.
  • Tidak diinstansiasi langsung menjadi objek.
  • Diletakkan di urutan kiri pada deklarasi class.

Keuntungan Mixin

  • Dapat disematkan ke class bisnis mana saja.
  • Meningkatkan reusabilitas kode tanpa polusi hierarki.
  • Contoh: JSONExportMixin, AuditLogMixin.
