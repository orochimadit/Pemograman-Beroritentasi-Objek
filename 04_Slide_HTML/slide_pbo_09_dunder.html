Fondasi Arsitektur

Protokol Dunder Methods

Representasi Objek

  • __str__: Ditampilkan untuk pengguna akhir (print/str).
  • __repr__: Ditampilkan untuk developer saat debugging di terminal.
  • Standar: repr harus unambiguous dan idealnya menyerupai kode inisialisasi.

Operator Overloading

  • __add__: Memungkinkan operasi objek1 + objek2.
  • __eq__: Membandingkan kesamaan nilai dengan ==.
  • __lt__: Mengurutkan objek dengan operator <.

Referensi: Python Object-Oriented Programming (4th Edition).

Implementasi Teknis

Protokol Koleksi Objek

Karakter Koleksi

  • __len__: Mengembalikan jumlah item saat dipanggil len(obj).
  • __getitem__: Membaca item dengan indeks obj[0].
  • __contains__: Mengecek keanggotaan via in.

Keuntungan Teknis

  • Sintaks kode klien menjadi bersih dan intuitif.
  • Objek terintegrasi mulus dengan fungsi bawaan Python.
  • Mencegah pembuatan method kaku seperti tambah() atau hitung().
